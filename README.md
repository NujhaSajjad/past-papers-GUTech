# 🎓 University Past Papers Repository

Welcome to the University Past Papers Repository!

This repository is created to help students easily access and share past examination papers for exam preparation.

## 🎯 Purpose

- Provide easy access to university past papers.
- Help students prepare for examinations.
- Keep academic resources organized in one place.
- Encourage students to contribute useful resources.

## 🤝 Contributions

Have past papers that aren't available here?

You are welcome to contribute!

1. Fork this repository.
2. Add papers to the appropriate semester and subject folder.
3. Submit a Pull Request.

Please make sure uploaded files are properly named and placed in the correct folders.

## ⭐ Support

If you find this repository helpful, consider giving it a star and sharing it with fellow students!

**Happy Learning & Best of Luck with Your Exams!**
